# 🍷 Calculateur de Coefficients - Provence

Calculateur interactif pour les vins de Provence Sylvins.

## Fonctionnalités

- 📋 Liste complète des vins Domaines de Provence
- 🔢 Calcul automatique des quantités et cartons
- 💰 Tarification progressive (36, 60, 120 bouteilles)
- 📊 Résumé de commande détaillé

## Utilisation

1. Sélectionner un vin dans la liste
2. Entrer le nombre de bouteilles (ou cliquer sur un bouton prédéfini)
3. Voir le prix et les cartons calculés automatiquement
